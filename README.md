# ZeppelinForms solution

## RUS

ZeppelinForms (ZF) - экспериментальный проект простого UI фреймворка, который берет прямолинейность из WinForms и \[потенциальный\] кроссплатформ из Avalonia.

1. Нет зависимостей от `System.Windows.Forms` и `System.Drawing`. Графика на SkiaSharp со своими примитивами
2. Нет привязки контролов к Win32 сущностям. Нужно только создание окна
3. Нет дизайнера форм =(
4. В то же время нет XAML, MVVM из WPF+ фреймворков
