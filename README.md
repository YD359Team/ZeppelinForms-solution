# ZeppelinForms

## RUS

**ZeppelinForms** (ZF) - проект-эксперимент по созданию простого UI-фреймворка без привязки к Windows, с аппаратным ускорением, простым code-behind созданием элементов. 

### Философия

Объединить простоту WinForms с некоторыми идеями WPF, кроссплатформенностью Avalonia, и выкинув тонны легаси в процессе. \
А если проект современный, то почему бы не использовать все богатые возможности .NET 10 и C# 14? 

### Контролы

#### Обычные контролы

**Обычные контролы** - похожи на Control из мира WinForms. У них не может быть дочерних контролов.

| № | Название      | Статус |
|---|------------|---|
| 1 | Label      | ✅ |
| 2 | Button     | ✅ |
| 3 | CheckBox   | ✅ |
| 4 | PictureBox | ✅ |
| 5 | RadioButton | 💡 |
| 6 | TextBox | 💡 |
| 7 | ToggleSwitch | 💡 |
| 8 | DataTimePicker | 💡 |

#### Панели

**Панели** - контролы, которые могут включать в себя другие контролы (в том числе другие панели).

| № | Название      | Статус |
|---|------------|---|
| 1 | StackPanel      | ✅ |
| 2 | Grid     | ✅* |
| 3 | DockPanel | 💡 |

\* - не хватает только `ColumnLength.Auto`

#### Контролы-обёртки

**Контролы-обёртки** - контролы, которые могут включать в себя один контрол. Необычная для WinForms мира, но знакомая в мире XAML-фреймворков.

| № | Название      | Статус |
|---|------------|---|
| 1 | Border      | ✅ |
| 2 | Spoiler     | ✅ |
| 3 | ZoomBox     | ⚙️ |
